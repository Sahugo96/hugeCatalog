# HugeCatalog

Сайт-каталог манги, манхвы, маньхуа и комиксов с читалкой, командами переводчиков и модерацией.

**Стек:** Node.js ≥ 22.13 · Express 5 · EJS (серверный рендеринг) · встроенный SQLite (`node:sqlite`) · чистый CSS/JS без сборки.

## Быстрый старт

```bash
npm install
```

```bash
ADMIN_PASSWORD=придумайте-пароль npm start
```

Откройте http://localhost:3000. При первом запуске создаётся администратор `admin` (пароль — из `ADMIN_PASSWORD`; если переменная не задана, пароль генерируется и печатается в консоль).

Демо-данные (16 тайтлов с главами, команда `Demo Scans`, пользователь `demo` / `demo12345`):

```bash
npm run seed:demo
```

Тесты:

```bash
npm test
```

## Возможности

### Страницы
| Страница | Адрес | Что есть |
|---|---|---|
| Главная | `/` | баннер популярного, «Продолжить чтение», **Свежие обновления**, **Топ за сегодня**, **Читаемые сегодня**, **Новинки**, Топ недели, Завершённые, облако жанров |
| Каталог | `/catalog` | фильтры по типу, жанрам, тегам, статусу, языку, возрасту, году, числу глав, автору, команде. Каждый критерий можно **включить** (1 клик) или **исключить** (2 клика / правый клик); для жанров и тегов — режим «все выбранные / любой из». Сортировка, поиск, активные фильтры чипами |
| Тайтл | `/title/:slug` | обложка, счётчики просмотров/лайков/избранного, автор и художник, тип, год, статус, язык, возрастной рейтинг, жанры и теги — **всё ссылки на каталог с этим критерием**; описание; список глав с датами, поиском и сортировкой; **похожие** по жанрам/тегам, по сюжету и по рисовке; лайк и избранное для авторизованных |
| Читалка | `/title/:slug/chapter/:id` | лента или постраничный режим, ширина страниц, выбор главы, клавиши ← → / A D / F, свайпы, прогресс, запоминание последней главы |
| О сайте | `/about` | описание, как стать командой, правила |
| Политика | `/privacy` | политика конфиденциальности |
| Профиль | `/profile` | избранное, лайки, история чтения, мои команды |
| Команды | `/teams`, `/team/:slug` | список команд, страница команды, участники |
| Студия | `/studio` | загрузка тайтлов и глав командами |
| Админка | `/admin` | модерация команд и тайтлов, жанры/теги/авторы, пользователи и роли |

Дневная и ночная темы: по умолчанию следуют системной, переключатель в шапке запоминает выбор.

### Роли и модерация
1. Любой посетитель может **зарегистрироваться** — получает лайки, избранное, историю чтения.
2. Пользователь подаёт **заявку на создание команды** → модератор одобряет или отклоняет с причиной.
3. Участники одобренной команды добавляют **тайтлы** (обложка, авторы, жанры, теги, год, язык, тип, рейтинг) → тайтл виден только команде и модераторам, пока **администратор не опубликует** его.
4. Главы загружаются сразу: выберите изображения — порядок страниц берётся из имён файлов (`1.jpg`, `2.jpg`, … `10.jpg`).
5. Роли: `user`, `moderator` (модерация, жанры и теги), `admin` (ещё и пользователи/роли/блокировки). Тайтлы, добавленные модератором или админом, публикуются без проверки.

### Как ищутся похожие
- **По жанрам и тегам** — взвешенное пересечение (жанр важнее тега).
- **По сюжету** — TF-IDF-сходство описаний (с простым стеммингом для русского) + общие теги группы «Сюжет».
- **По рисовке** — общий художник, теги группы «Рисовка» (цветная, чёрно-белая, реалистичная…), совпадение типа.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | порт |
| `SESSION_SECRET` | — | **обязательно в production** |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` / `ADMIN_EMAIL` | `admin` / случайный / `admin@localhost` | первый администратор |
| `DATA_DIR` | `./data` | база и загруженные файлы |
| `SITE_NAME` | `HugeCatalog` | название сайта |
| `COOKIE_SECURE` | — | `1` при работе по HTTPS |
| `TRUST_PROXY` | — | `1`, если сайт стоит за nginx/прокси |

Всё состояние хранится в `DATA_DIR` (`hugecatalog.db` + `uploads/`) — для бэкапа достаточно копировать эту папку.

## Безопасность
- пароли — scrypt с солью; сессии в SQLite, cookie `httpOnly` + `SameSite=Lax`;
- CSRF-токен во всех формах и AJAX-запросах;
- загрузки проверяются по сигнатуре файла (jpg, png, webp, gif, avif), отдаются с `nosniff` и `sandbox`-CSP;
- ограничение частоты попыток входа и регистрации.
