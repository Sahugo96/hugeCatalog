# Расширение «HugeCatalog: импорт»

Копирует данные открытой страницы в буфер обмена в формате импорта HugeCatalog. Поддерживаются:
- **3hentai** — страница галереи `…3hentai.net/d/123456`;
- **hentai2read** — страница произведения, например `https://hentai2read.com/original/74273-mother-son-incest-jealousy/` (не страница чтения с номером главы в конце адреса).

## Установка (Chrome, Edge, Яндекс Браузер, Opera)
1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `browser-extension`.

Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → файл `manifest.json` (до перезапуска браузера).

## Использование
1. Откройте страницу галереи 3hentai или страницу произведения hentai2read.
2. Нажмите на значок расширения — данные сразу окажутся в буфере обмена, во всплывающем окне видно, что распознано.
3. На своём сайте: «Админка → Импорт» → вставьте → отметьте «Создавать отсутствующие жанры и теги» → «Импортировать».

Флажок «Собирать несколько страниц в один импорт» копирует сразу весь накопленный список — удобно, чтобы импортировать серию за один раз.

## Что берётся со страницы 3hentai
Расширение берёт **все** данные из родительского блока галереи (`#main-info`), ничего не отбрасывая:
- каждое поле `.tag-container` — категории, серия/пародия, персонажи, художники, группы, языки, теги и любые другие подписи. Все значения как есть также лежат в `source_fields`;
- **теги** — все до одного. У каждого есть оригинальное название (`name_en`) и группа: обычные теги → «Прочее», персонажи → «Персонажи», пародия → «Пародия». Русское название подставляется из встроенного словаря, если оно там есть, иначе тег создаётся с английским названием — его можно переименовать в админке, перевод при этом сохранится;
- название `[Кружок (Автор)] Серия №2 ~подзаголовок~ / Перевод [Russian][Команда]` → серия, номер и название главы, перевод названия, язык, команда перевода; кружок и художник → авторы;
- обложка — `cover.jpg` из блока галереи (запасной вариант — первая страница в полном размере);
- количество страниц и дата загрузки;
- формат: если в названии нет номера и на странице нет тега «multi-work series», галерея считается **синглом** (`"format": "single"`). Если на сайте эта серия уже ведётся по главам, импорт всё равно добавит её главой.

При импорте тег сначала ищется среди существующих по русскому названию и по полю «English», и только потом создаётся новый. Выпуски одной серии на одном языке собираются в одно произведение с главами, версии на разных языках связываются. Страницы глав не копируются: импорт создаёт пустую главу, она появится у читателей после загрузки страниц командой в студии.

## Что берётся со страницы hentai2read
Тот же принцип: от заголовка произведения расширение поднимается до родительского блока со всеми полями вида «**Подпись** значения» и забирает каждое поле. Все поля как есть лежат в `source_fields`, так что новые или переименованные поля сайта не теряются.
- **Oneshot** в любом поле (обычно «Category») означает **сингл**: `"format": "single"`, без глав. Сам «Oneshot» тегом не становится.
- Не сингл: каждая глава из списка на странице (ссылки `<страница произведения>/<номер>/`) становится отдельной записью с `series` и `chapter`. Импорт соберёт их в одно произведение с главами-каркасами. Если глав на странице не найдено, импорт создаст произведение без глав.
- Название — из заголовка, альтернативные названия — из `<small>` в заголовке и полей вроде «Alternative».
- Artist → художники; Author (если поля нет — художники) → авторы.
- Category: Doujinshi/Manhwa/… → тип (иначе «манга»); остальные значения → теги.
- Content и прочие поля со ссылками → теги «Прочее», Character → «Персонажи», Parody (кроме Original) → «Пародия».
- Status → статус (у сингла по умолчанию «завершён»), Release Year → год, Page → число страниц, Storyline → описание, Language → язык (по умолчанию английский).
- Обложка — картинка блока произведения (`.img-container img` или картинка с `cover` в адресе), запасной вариант — `og:image`.
- Русские названия тегов подсказывает словарь `tags-ru.js`.
- Сканы (страницы глав) с hentai2read не собираются.
