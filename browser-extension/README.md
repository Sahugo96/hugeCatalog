# Расширение «HugeCatalog: импорт с 3hentai»

Копирует данные открытой галереи 3hentai в буфер обмена в формате импорта HugeCatalog.

## Установка (Chrome, Edge, Яндекс Браузер, Opera)
1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `browser-extension`.

Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → файл `manifest.json` (до перезапуска браузера).

## Использование
1. Откройте страницу галереи, например `https://ru.3hentai.net/d/682609`.
2. Нажмите на значок расширения — данные сразу окажутся в буфере обмена, во всплывающем окне видно, что распознано.
3. На своём сайте: «Админка → Импорт» → вставьте → отметьте «Создавать отсутствующие жанры и теги» → «Импортировать».

Флажок «Собирать несколько галерей в один импорт» копирует сразу весь накопленный список — удобно, чтобы импортировать серию за один раз.

## Что берётся со страницы
Расширение берёт **все** данные из родительского блока галереи (`#main-info`), ничего не отбрасывая:
- каждое поле `.tag-container` — категории, серия/пародия, персонажи, художники, группы, языки, теги и любые другие подписи. Все значения как есть также лежат в `source_fields`;
- **теги** — все до одного. У каждого есть оригинальное название (`name_en`) и группа: обычные теги → «Прочее», персонажи → «Персонажи», пародия → «Пародия». Русское название подставляется из встроенного словаря, если оно там есть, иначе тег создаётся с английским названием — его можно переименовать в админке, перевод при этом сохранится;
- название `[Кружок (Автор)] Серия №2 ~подзаголовок~ / Перевод [Russian][Команда]` → серия, номер и название главы, перевод названия, язык, команда перевода; кружок и художник → авторы;
- обложка — `cover.jpg` из блока галереи (запасной вариант — первая страница в полном размере);
- количество страниц и дата загрузки.

При импорте тег сначала ищется среди существующих по русскому названию и по полю «English», и только потом создаётся новый. Выпуски одной серии на одном языке собираются в одно произведение с главами, версии на разных языках связываются. Страницы глав не копируются: импорт создаёт пустую главу, она появится у читателей после загрузки страниц командой в студии.
