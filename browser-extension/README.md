# Расширение «HugeCatalog: импорт с 3hentai»

Копирует данные открытой галереи 3hentai в буфер обмена в формате импорта HugeCatalog.

## Установка (Chrome, Edge, Яндекс Браузер, Opera)
1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `browser-extension`.

Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → файл `manifest.json` (до перезапуска браузера).

## Использование
1. Откройте страницу галереи, например `https://ru.3hentai.net/d/682609`.
2. Нажмите на значок расширения — данные сразу окажутся в буфере обмена, во всплывающем окне видно, что распознано.
3. На своём сайте: «Админка → Импорт» → вставьте → отметьте «Создавать отсутствующие жанры и теги» → «Импортировать».

Флажок «Собирать несколько галерей в один импорт» копирует сразу весь накопленный список — удобно, чтобы импортировать серию за один раз.

## Что распознаётся
- `[Кружок (Автор)] Название №2 / Перевод названия [Russian][Команда]` → серия, номер главы (`№2`, `#2`, `Vol. 2`, `Part 2`, `Глава 2`, число в конце), подзаголовок `~…~` как название главы, язык, команда перевода, кружок и автор;
- язык из тегов `/language/…`, тип из категории, теги сайта → теги каталога (неизвестные показываются отдельно и не импортируются);
- обложка — первая страница в полном размере.

Выпуски одной серии на одном языке собираются в одно произведение с главами, версии на разных языках связываются. Страницы глав не копируются: импорт создаёт пустую главу, она появится у читателей после загрузки страниц командой в студии.
