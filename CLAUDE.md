# CLAUDE.md — память проекта HugeCatalog

Сайт-каталог манги/манхвы/маньхуа/додзинси с читалкой, командами переводчиков, модерацией, чатом, уведомлениями, интерфейсом ru/en. Владелец — администратор сайта; общение с ним на русском.

**Полное описание устройства, БД, логики и функционала по ролям — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Читать перед работой.**

## Кратко
- Node.js ≥ 22.13, Express 5, EJS, встроенный `node:sqlite`, `multer`, `sharp`. Без сборки фронтенда.
- Запуск `npm start` (берёт `.env`), тесты `npm test` (должны проходить все), демо `npm run seed:demo`.
- Ветка разработки: `claude/stoic-maxwell-gkpbhr` (репозиторий `Sahugo96/hugeCatalog`). Владелец тоже пушит в неё — перед работой `git fetch` и `git pull --ff-only`.
- Пароль администратора хранится только в `.env` (`ADMIN_PASSWORD`), в репозиторий не записывать.

## Правила работы с кодом
- **Миграции**: новые колонки — в `src/db.js` через `hasColumn` + `ALTER TABLE`; новые таблицы — в `src/schema.sql`. База владельца уже существует.
- **Переводы**: любой новый текст интерфейса — через `__('русский текст')` в шаблонах, `req.__()` на сервере, `T()` в `public/js`; английский перевод — в `src/i18n/en.js` (ключ = русская строка, `{плейсхолдеры}` для динамики). Новые множественные формы — в `PLURALS`.
- **CSRF**: формы — скрытое поле `_csrf`; fetch — заголовок `X-CSRF-Token`; multipart — `verifyCsrf` после multer.
- **Видимость**: публично только `moderation = 'approved'`; главы с `pages_count = 0` скрыты; используйте `W.getChapters(id, order, { includeEmpty })`.
- **Удаление**: только через `W.deleteWork` / `removeChapterFiles` (чистят файлы страниц по путям из `pages`, WebP, миниатюры, `uploads/works/<slug>`).
- **Картинки**: сохранять через `storeImage` (проверка сигнатуры + фоновый WebP).
- **SSE**: одно соединение на браузер (ведущая вкладка + BroadcastChannel) — не открывать EventSource в каждой вкладке.
- Проверять изменения в браузере (Playwright: `require('playwright')`, для русских страниц `locale: 'ru-RU'`, иначе сайт отдаёт английский по Accept-Language).
- В этой среде heredoc с некоторыми словами может блокироваться проверкой безопасности — тогда правки через Edit/Write.

## Принятые решения (не пересматривать без запроса владельца)
- Просмотры = прочтения глав вошедшими пользователями, один раз на пользователя и главу.
- Сингл = одна служебная глава-галерея; смена формата — только admin, с подтверждением удаления лишних глав.
- Причина `admin` при отклонении/снятии с публикации (только у роли admin) = полное удаление тайтла.
- Ссылка «Студия» — только в меню пользователя; «Случайное» — иконка кубиков без текста; переключатель языка — только в меню пользователя.
- Личные переписки доступны администратору для модерации; пользователи об этом предупреждены (окно чата, правила, политика).
- **Сканы с чужих сайтов**: владелец сам написал скачивание сканов в импорте (`scans_gallery` → `uploads/works/<slug>/`). Claude этот код не удаляет и не ломает, но **не пишет, не чинит и не встраивает** автоматическое скачивание чужих сканов и их запись в `pages` (это распространение чужих работ без прав). Метаданные и обложки — можно. Если код владельца ломает остальное — сказать, где проблема. Предложено вместо этого: загрузка главы ZIP-архивом в студии (не сделано, ждёт ответа).
